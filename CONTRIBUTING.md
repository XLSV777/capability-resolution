# Contributing

Thank you for taking a look.

- **Questions and corrections to the spec:** open an issue. Quote the section number.
- **Changes to the text:** a pull request against `spec/`. Spec text you contribute is licensed CC BY 4.0, code MIT.
- **Another implementation:** a resolver, a client or a gateway integration. Open an issue so we can list it and run
  the checker against it. The spec is designed for many resolvers; a second implementation matters more than anything else.
- **Co-editing:** if you run a resolver, a gateway or a client and want to co-edit, say so in an issue.

Published versions never change. Each one is timestamped in `proof/`; fixes go into the next version.

Security problems in the reference code: please write to lior@7it.co.il with "Security" in the subject, not a public issue.
